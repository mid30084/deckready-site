How DeckReady works

DeckReady is a desktop app for macOS and Windows that finds your tracks on Beatport and writes the correct tags into the files. Here is the whole process, from a folder of badly tagged files to a library your DJ software can sort properly.

1. Choose your music

Click Choose folder or files, or drag a folder or single files straight into the window. DeckReady works with MP3, FLAC, AIFF and WAV files, so a mixed folder of downloads, promos and rips is fine.

2. Analyze — nothing is written yet

Click Analyze. DeckReady looks up every track on Beatport, using the artist and title from the file’s tags or from its file name. You can pause or stop the analysis at any time.

The analysis only looks for matches. No file is changed at this stage — your tags stay exactly as they were until you decide to write.

DeckReady also compares the length of your file with the versions on Beatport, so an Extended Mix is not confused with a Radio Edit of the same track. Beatport answers and artwork are cached, so analysing the same tracks again is almost instant.

3. Read the result tabs

Every track lands in one tab. The number next to a tab name is how many files it holds.

  • Ready to Write — the track was found on Beatport with a good match.
  • Review Manually — Beatport found a similar track, but the match isn’t complete. The decision is yours.
  • No Matches — Beatport found nothing. Usually the file’s tags are empty or wrong.
  • Errors — the file couldn’t be processed: it is empty, damaged, missing from disk, or Beatport temporarily limited requests.
  • Processed — tracks from this session whose tags are already written.
  • No Action Needed — files DeckReady already processed earlier.

The Match column shows a bar: green for a match of 95% or more, orange below that. In Settings you can choose how close a match must be to land in Ready to Write.

4. Review close calls and pick the right version

Click a row and your file’s data appears next to Beatport’s. Two waveforms sit on top of each other — your file and the Beatport preview — and a click on either one plays from that point. The lengths underneath turn green when they match and red when they differ.

If a track in Review Manually is right, move it to Ready to Write. If the version is wrong — say, the Original Mix instead of the Extended — open Choose Version Manually. It lists every version of the track on Beatport and highlights the ones whose length matches your file. Listen, pick one and click Use as match. If the right version isn’t listed, paste a Beatport track link into Beatport track link: and click Add to list.

For files in No Matches, fix the file name or tags and click Re-analyze, or add the track by its Beatport link in the same way.

5. Choose which tags to write

Check the tracks you want and click Write Beatport Tags. Before anything is written, the Which Tags to Write window opens:

  • Beatport data — every field has three states: take Beatport’s value, keep your own (for example, if you use your own genre system), or remove the field from the file.
  • Other tags in the files — tags Beatport doesn’t have, such as a rating, DJ software markers or links. Checked tags stay in the file, unchecked ones are removed.

DeckReady writes title, artist, remixer, album, genre, BPM, key, label, track number, release date, catalog number and artwork. The key is written the way Beatport names it, in short form — Am, F#m or Eb — not in Camelot notation. WAV files get ID3 tags, and the basic fields — title, artist, album, genre, date and track number — are also written as RIFF INFO, so other apps can read them.

Your choice is remembered. If you uncheck Ask before each write, the window stops appearing and your last choice is used.

6. Reload the tags in your DJ software

DJ software doesn’t notice new tags on its own — it keeps showing the old data until it reads the files again. After writing, rescan the tags as your DJ app’s manual describes; Help → How to Reload Tags in DJ Software… reminds you. There are separate guides for rekordbox and for Serato, Traktor and Engine DJ.

More tools in the app

  • Find Duplicates — finds copies of the same track across all analysed files, suggests which copy to keep and sends the extras to the system Trash or Recycle Bin, never deleting them for good. One copy of every track always stays.
  • Edit tags… — change tags by hand, for one file or many.
  • Rename File → By Tags — rename checked files using their tags.
  • Sessions — the last analysis is restored on the next launch, and Save Session / Load Session keep separate ones.
  • Search tracks… — search all tabs at once (⌘F on Mac, Ctrl+F on Windows).
