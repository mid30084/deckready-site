Serato, Traktor & Engine DJ guide

DeckReady for Serato, Traktor and Engine DJ

Whatever DJ software you play with, it can only show what is in your tags. DeckReady fills them with Beatport data — and lets you keep the cue points and beatgrids your DJ app stored in the files.

One workflow for every DJ app

DeckReady writes standard tags into the audio files — MP3, FLAC, AIFF and WAV — so the same clean data works in Serato, Traktor, Engine DJ and any other software that reads tags:

  1. Click Choose folder or files and then Analyze. Nothing is written during the analysis.
  2. Write the confident matches from Ready to Write, and check Review Manually for close calls; Choose Version Manually fixes a wrong version.
  3. Click Write Beatport Tags and pick in Which Tags to Write which fields to take from Beatport and which to keep.
  4. Reload the tags in your DJ software.

DeckReady writes title, artist, remixer, album, genre, BPM, key, label, track number, release date, catalog number and artwork. The key is written as Beatport names it — Am, F#m or Eb — not in Camelot notation.

Check a match before you write

Click any row to see your file’s data next to Beatport’s. The top waveform is your file and the bottom one is the Beatport preview; a click on either plays from that point, so you can hear in a second whether it is the same track. In the Match column, a green bar means a match of 95% or more, an orange one means it is worth a listen first. The lengths under the waveforms turn red when your file is noticeably longer or shorter — often a sign of another version.

Keep your cue points and beatgrids

Some DJ software stores its own data, such as cue points and beatgrids, inside the audio files. DeckReady shows such fields in the Which Tags to Write window under Other tags in the files — for example fields named “Serato …” or Traktor: cues and grid. Checked fields stay in the file; unchecked ones are removed. If you rely on them, make sure they are checked before you write. Your choice is remembered for the next time.

Serato

Serato reads the tags from the files, but tracks already in your library keep their old values until Serato reads them again. In Serato DJ, the Files panel has a “Rescan ID3 Tags” button that re-reads the tags of your tracks. If your version works differently, check the Serato manual.

Traktor

Traktor keeps track information in its collection. After DeckReady writes new tags, tell Traktor to read the tags from the files again — see the Traktor manual for your version. Until then, Traktor shows the values it read before.

Engine DJ

Engine DJ also keeps its own library. After writing, refresh the track information in Engine DJ so it reads the new tags from the files — the Engine DJ manual describes how for your version.

WAV, AIFF and FLAC

DeckReady writes each tag in the right place for the format. WAV files get ID3 tags, and the basic fields — title, artist, album, genre, date and track number — are also written as RIFF INFO, so different apps can read them. Lossless files are also preferred when DeckReady’s Find Duplicates decides which copy of a track to keep — FLAC first, then AIFF, then WAV, and MP3 last.
