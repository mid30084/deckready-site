rekordbox guide

Prepare your rekordbox library with DeckReady

Correct genre, BPM, key and artwork make a rekordbox library easy to browse. DeckReady writes them from Beatport into your files — before you import, or for tracks you already have.

Why tags matter in rekordbox

Browsing by genre, filtering by BPM, mixing in key — all of it depends on the information stored with each track. Files from downloads, promo pools and old folders often arrive with empty fields, different genre names for the same style, or a key in one file and none in the next. In rekordbox that shows up as blank columns and messy sorting.

DeckReady fixes the source: it finds each track on Beatport and writes title, artist, remixer, album, genre, BPM, key, label, track number, release date, catalog number and artwork into the audio file itself.

Tag the files before you import them

The cleanest way is to tag a folder first and import it afterwards:

  1. Click Choose folder or files and pick the folder you are about to import.
  2. Click Analyze. Nothing is written yet — the app only looks for matches.
  3. Check Ready to Write, then look at Review Manually for close calls and use Choose Version Manually if a version is wrong.
  4. Click Write Beatport Tags and choose in Which Tags to Write which fields to take from Beatport.
  5. Import the folder into rekordbox.

The key is written the way Beatport names it — Am, F#m or Eb — not in Camelot notation.

Tracks already in your collection

rekordbox keeps its own copy of the track information in its library. After DeckReady writes new tags, rekordbox keeps showing the old values until you tell it to read the tags from the files again.

Select the updated tracks in rekordbox and use its reload-tag function — in recent versions it is in the track’s right-click menu as “Reload Tag”. If you don’t see it, check the rekordbox manual for your version. Inside DeckReady, Help → How to Reload Tags in DJ Software… is a reminder.

Your cue points and rekordbox library

DeckReady only changes tags inside the audio files. It does not open or edit rekordbox’s library. Tags in the files that Beatport doesn’t have — a rating, DJ software markers, links — are listed under Other tags in the files before writing: keep them checked and they stay.

WAV files and artwork

rekordbox doesn’t show embedded covers for WAV files. This is a rekordbox limitation: DeckReady writes the cover into the WAV correctly, and other software shows it. WAV files get ID3 tags, and the basic fields — title, artist, album, genre, date and track number — are also written as RIFF INFO.

Getting the right version

DJs often buy the Extended Mix, while a search finds the Original or the Radio Edit first. DeckReady compares the length of your file with every version on Beatport and picks the one you actually have. When it isn’t sure, the track waits in Review Manually, where you can listen to your file and the Beatport preview side by side before deciding.
